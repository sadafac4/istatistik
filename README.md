# istatistik


10. Karma yöntemler kısmı için bana güzel özet bir slayt lazım. Güzel tıbbi örnekler ekleyebilirsin.
En sona da bir özet kısmı ekleyebilirsin güzel olur bence. Punto çok küçük olmasın okunabilir olmalı. Bir sunum şeklinde hazırla bu kısmı Karma yöntemler kısmını anlatacağım kısım şeklinde.
